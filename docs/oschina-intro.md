## 软件介绍

ollmo 是一个生产级的 RAG（检索增强生成）平台，目标是把"让 AI 读懂你自己的文档"这件事做到极致简单：**上传文档、提出问题、拿到带出处的答案**，三步完成。

与市面上堆砌工作流、节点、插件概念的 AI 编排平台不同，ollmo 遵循三个设计原则：

- **简单** — 只做一件事并做到极致：把你的文档变成能问答的助手；
- **易用** — 一条命令部署，十分钟上手，不需要先学会一套比业务还复杂的系统；
- **克制** — 不堆概念、不加多余配置，复杂留在系统内部，简单留给你。

ollmo 提供混合检索、多租户隔离与流式对话能力，支持团队私有化部署，数据全程不出内网，适合企业内部知识库、客服问答、文档助手等场景。

## 核心特性

- **混合检索**：基于 Milvus 2.5+ 的稠密 + 稀疏向量检索，支持知识库级 Rerank 重排配置，检索效果可精细调优；
- **文档流水线**：上传（拖拽、粘贴、多文件）→ 解析（MinerU / 本地解析器）→ 分块 → 向量化 → 索引，全程异步处理，支持多种分块策略；
- **流式对话**：SSE 实时流式输出，答案带来源引用，可追溯原文出处；
- **自动记忆**：长对话自动生成摘要并注入后续会话，实现跨对话上下文延续；
- **Agent 画布**：可视化编排 Agent 流水线（意图分类 → 检索 → 条件分支 → LLM → 回复），支持知识库级系统提示词、温度、检索参数配置；
- **数据处理流水线画布**：可视化配置入库 DAG（来源 → 解析器 → 分块器 → 向量化 → 存储）；
- **GraphRAG**：入库时自动抽取实体与关系，查询时实体匹配增强检索上下文；
- **多租户隔离**：MySQL、Milvus、MinIO 全链路逻辑隔离，适合团队与 SaaS 化运营；
- **模型可配置**：租户级管理 LLM / Embedding / Rerank 模型，兼容 OpenAI 协议的任意供应商（含本地模型）；
- **团队与权限**：邀请制成员管理、角色权限（所有者 / 管理员 / 成员）、知识库级访问控制、每用户每日消息配额；
- **管理控制台**：用户管理、团队计划与配额、系统设置、数据分析看板、审计日志；
- **外部 API**：API Key 鉴权的编程式访问（检索、知识库管理、流式对话），便于二次集成；
- **国际化**：中英文双语界面。

## 技术架构

| 层 | 选型 |
|---|---|
| 后端 | Go 1.26+ / Fiber / GORM |
| 前端 | Next.js 15（App Router）/ React / shadcn/ui |
| 元数据库 | MySQL 8.0 |
| 向量库 | Milvus 2.5+（稠密 + 稀疏混合检索） |
| 对象存储 | MinIO（S3 兼容） |
| 任务队列 | Asynq + Redis（解析、向量化、自动摘要） |
| 文档解析 | MinerU（容器化，可选 GPU）+ 本地解析器 |

后端 API 与异步 Worker 共用同一二进制，按业务领域划分模块；前端基于 Next.js App Router，对话页与管理后台一体化。Docker Compose 一条命令即可拉起全栈。

## 应用场景

- 企业内部知识库问答（制度、手册、产品文档）
- 客服 / 售前智能助手
- 研发文档与技术资料检索
- 个人知识管理与第二大脑

## 快速体验

```bash
git clone https://gitee.com/ollmo-go/ollmo.git
cd ollmo
cp .env.example .env
docker compose up -d --build
docker compose exec server ./ollmo migrate
```

访问 http://localhost:3001，首次进入安装向导，注册第一个账号即为团队管理员。也可直接访问在线演示：https://demo.ollmo.com
